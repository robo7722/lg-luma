# UI sounds

`assets/sounds/*.wav` (focus, select, back, bump) were generated with
ElevenLabs Sound Effects (eleven_text_to_sound_v2) for this fork and then
trimmed, layered, pitched and level-matched by hand. Format: 48 kHz, mono,
16-bit PCM WAV.

Sound effects generated by ElevenLabs. Check the ElevenLabs terms for the
account's plan before any commercial redistribution.
